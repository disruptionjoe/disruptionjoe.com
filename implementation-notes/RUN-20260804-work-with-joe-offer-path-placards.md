## Display hierarchy

Each of the five Work With Joe displays now uses a distinct communication
sequence:

1. The small gold eyebrow names the canonical offer path.
2. The static title begins with the path number and uses the ratified human
   subtitle.
3. The static body mirrors the visitor's situation.
4. Proximity opens the dynamic placard directly on its outcome headline.
5. The dynamic body explains the progress Joe helps create.
6. The button opens the matching Planning Room path.

The dynamic placard deliberately has no eyebrow or `WHAT YOU LEAVE WITH`
label. Desktop, mobile story cards, and mobile inspectors share the same
structure and copy.

## Conversion alignment

The AI Capability Soundcheck and Planning Room now use the same five canonical
path names:

1. Identify the Floor
2. Establish the Floor
3. Raise the Floor
4. Lead the Change
5. Push the Frontier

This alignment changes navigation language, not Offer Portfolio scope,
pricing, packaging, methodology, or client promises.
