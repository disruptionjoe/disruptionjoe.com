# Give Start Here a dynamic guide placard

## Objective

Make the Start Here installation easier to read from across the Work With Joe
room while revealing its navigation instructions only when someone approaches.

## Result

- Removed the entire lower `Start to Your Right` instruction panel from the
  physical wall texture.
- Reflowed the approved AI Activation explanation and stages 01–05 across the
  full wall surface with materially larger typography:
  - title: `38px` to `54px`
  - explanation: `42px` to `56px`
  - section headings: `30px` to `42px`
  - stage numbers: `50px` to `64px`
  - stage names: `35px` to `44px`
- Appended a virtual `Start Here` exhibit without shifting any existing exhibit
  index.
- Registered the existing plaque face and installation anchor with the standard
  desktop proximity system.
- The dynamic placard now reads:
  - `Start to your right →`
  - `Walk close to each display to see more. Look for the stage that sounds
    most like where you are now. Not sure? Use the AI Capability Soundcheck for
    a quick self-diagnosis.`

## Preserved

The Start Here neon, installation dimensions, `0.8` scale, vertical centering,
wall location, frame, lighting, five product displays, Soundcheck, room
geometry, existing exhibit indexes, and mobile experience remain unchanged.

## Validation

- JavaScript syntax and repository tests.
- Exact exhibit-index append and interaction/anchor wiring checks.
- Canvas-copy removal and large-type layout checks.
- Five-stage story, physical-installation, product-order, mobile, YAML, and
  whitespace invariants.
- Fresh local desktop walkthrough of wall readability and the proximity placard,
  with no browser-console errors.
