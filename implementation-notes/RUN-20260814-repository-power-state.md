# Repository power-state treatment

Run: `RUN-20260814-110420-djc-website-repository-power-state-direct`

## Result

Repository-backed displays in the desktop Thinking Experience now read as one
connected operating network without applying the treatment to products,
offers, social links, doorway placards, or other non-repository exhibits.

- A double-track conduit surrounds each repository display and returns toward
  the room infrastructure.
- The existing static placard now includes a compact activity instrument that
  names the repository state, avoiding an additional mesh and draw call.
- Agent-active repositories use green-gold conduit that slowly moves between
  the normal tan and green-gold states.
- In-development repositories use a static warm-gold conduit.
- Standby has a static dark-bronze treatment ready for a repository whose
  current truth warrants it; no displayed repository is asserted to be in that
  state in this run.
- Church of AI repositories use a short wall return instead of forcing a
  conduit to the chapel's different-height ceiling.
- CapacityOS receives the same active treatment on its viewer-facing command
  placard above the center console.

The agent-active set is conservative and grounded in live automation truth:
AI Epistemology, the Disruption Joe Website updater, GU Formalization, Drafting
Factory, System Lab, and System Attention, with CapacityOS represented as the
live orchestration hub coordinating that fleet.

## Rendering budget

- Only the green-gold material animates.
- The pulse runs at roughly 11 updates per second and only while an active
  repository is within an 18-unit room-scale radius.
- Reduced-motion visitors receive a steady green-gold state with no pulse.
- Existing demand rendering remains intact; there is no permanent render loop.
- All conduits sharing a state also share one material.
- The Development Laboratory chemistry table, meshes, light, bubbles, and
  nearby 24-fps update schedule were removed.
- The small status instrument was folded into the existing placard texture, so
  the conduit is the only new Three.js object per repository display.

## Verification

- Browser visual checks covered the Methods and Tools room at room scale and
  the Church of AI altar composition.
- The Methods room clearly distinguished active green, in-development gold,
  and untreated non-repository displays in one view.
- The Church of AI repository conduit terminated into the wall without
  depending on chapel ceiling height; the Substack display remained untreated.
- The active pulse stayed idle-scheduled only while an active repository was
  within the room-scale radius.
- Phone mode remained the existing mobile story/elevator experience and did
  not initialize repository power-state geometry.
- Browser console, repository tests, JavaScript parsing, and whitespace checks
  passed.

No form was submitted and no manual deployment was performed.
