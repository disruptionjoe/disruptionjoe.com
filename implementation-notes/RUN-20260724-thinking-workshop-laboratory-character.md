Methods and Tools now feels like a compact working tool shed, while the
Development Laboratory reads as an active chemistry workspace.

## Implemented

  frame to Methods and Tools.
- Added a framed pegboard with a recognizable hanging saw, saw teeth, hammer,
  pegs, and focused warm light.
- Added a narrow central chemistry table to the Development Laboratory with a
  flask, beaker, test-tube rack, liquids, support stand, and connected tubing.

- Added bounded fixture collision so visitors walk around both tables rather
  than through them.
- Preserved all five room exhibits, their approaches and interactions, doorway
  signs, room footprints, and mobile behavior.
