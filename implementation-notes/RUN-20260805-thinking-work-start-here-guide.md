# Work With Joe Start Here guide

## Objective

Replace the desktop Work With Joe `Plan a Call` physical button with a premium
in-world orientation artifact that explains the room's existing five-stage AI
Activation path.

## Result

- Removed only the Work With Joe Plan a Call button installation. The separate
  `Don't Press This Button` contact installation in the orientation room is
  unchanged.
- Added a dimensional black-and-gold plaque in the vacated east-wall bay, with
  a dedicated warm-gold `Start Here` neon above it.
- The plaque groups the existing sequence as:
  - Raise the Floor: `01` Understand where you are, `02` Build reliable AI ways
    of working, and `03` Connect what works and scale it.
  - Raise the Ceiling: `04` Help leaders guide AI-enabled change and `05` Push
    high-value work further.
- The final instruction points visitors to begin on their right, approach each
  display, and use the AI Capability Soundcheck for a quick self-diagnosis when
  they are not sure where they are.

## Preservation boundary

The five product displays, their copy, artwork, sizes, positions, proximity
behavior, and planning-call actions are unchanged. The AI Activation wall
graphic, Soundcheck installation, Methods and Tools entrance, Who Is Joe
entrance, room geometry, mobile experience, and all other rooms are unchanged.

## Validation

- JavaScript syntax and repository tests.
- Repository whitespace and scoped-diff checks.
- Local desktop walkthrough of the complete wall bay, including plaque
  legibility, neon placement, floor/ceiling grouping, and removal of the old
  physical button.
- Browser console check with no warnings or errors.
