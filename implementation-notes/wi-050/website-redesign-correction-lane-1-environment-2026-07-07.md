# Redesign Correction: Make Lane 1 The Website Environment

Status: correction brief for WI-050 homepage prototype and future full-site implementation
Date: 2026-07-07
Source: Joe-provided critique

The latest redesign is directionally useful in copy and layout, and the fonts are acceptable for now. But visually, it still feels like residue from the old site design. It looks like the old black / brown flat page system with a boxed diagram added on top.

That is not the intended direction.

The intended direction is that **Lane 1 becomes the actual design environment of the website**.

The site should feel like the visitor is entering a black-and-tan architectural wireframe world. The Lane 1 aesthetic should not be a decorative image, a side graphic, or a hero illustration. It should be the visual system that the page sits inside.

## First Task: Find And Remove Leaked Old Design Direction

Before redesigning, audit the current implementation and any planning / design files for instructions, tokens, or components that are preserving the old look.

Look for residue such as:

- flat brown / black gradient backgrounds
- boxy notebook panels that feel like the prior site
- old "field manual" styling that overwhelms the new visual world
- static cards floating on a flat page
- generic grid overlays
- tan borders used as decoration rather than spatial structure
- diagrams that sit beside the content instead of turning the page into an environment
- any prior design instruction that conflicts with the Lane 1 visual system

If old design direction is leaking into the build, remove it or supersede it explicitly.

Do not preserve old visual patterns just because they already exist in the repo.

## Correct Visual Standard

Lane 1 should become the visual architecture of the site.

Use this as the governing visual idea:

> The website should feel like stepping inside a black-and-tan architectural blueprint.

This means:

- the page background should be mostly black negative space
- warm brand-tan / camel-gold wireframe lines should define depth, structure, planes, thresholds, and spatial framing
- sections should feel like rooms, corridors, thresholds, galleries, operating rooms, labs, or designed spatial moments
- content should be framed by the environment, not merely placed on top of a flat background
- lines should feel architectural, dimensional, and intentional
- the visual system should create immersion without becoming noisy
- the brand should feel premium, restrained, cinematic, and spatial

The current right-side diagram is closer to an interface card. The target is a full-page spatial system.

## What Needs To Change

The website background and section architecture should use the Lane 1 aesthetic directly.

Do not treat Lane 1 as:

- a hero image only
- a decorative background texture
- a diagram card
- an accent motif
- a one-off visual asset

Treat Lane 1 as:

- the site's spatial frame
- the page atmosphere
- the section structure
- the transition system
- the background world
- the visual metaphor for entering the work

Each section should feel like it belongs inside the same black-and-tan architectural environment.

## Lane 1 Prompting Reference

Use this as the source prompt for the design language:

A minimal futuristic architectural wireframe environment rendered like a glowing blueprint in a black void. The image should use crisp, thin structural linework to define space, depth, edges, planes, openings, and form. Use a restrained palette of deep black with warm brand-tan glowing lines. The atmosphere should feel immersive, elegant, precise, and spatial, with a strong sense of structure and depth. The linework should be clean and intentional, not noisy or cluttered, with subtle glow and mostly empty black negative space between the lines. Avoid haze, smoke, particles, code-like noise, busy texture, people, logos, and excess detail.

Short version:

Minimal black-and-tan glowing architectural wireframe aesthetic in a black void. Clean blueprint linework, elegant negative space, immersive spatial depth. This environment should feel like [X].

## Design Translation

Translate that prompt into the website itself.

Examples:

- The homepage hero could feel like an entry threshold into the operating system.
- Services could feel like rooms or stations inside the environment.
- Method could feel like a mapped architectural sequence.
- Proof / outcomes could feel like illuminated signals inside the structure.
- Calls to action could feel like doorways, portals, or next-step thresholds.
- Section transitions could feel like moving from one designed space to another.

The visitor should not feel like they are scrolling a normal consulting website.

They should feel like they are moving through a designed system.

## Constraints

Keep:

- black and brand tan palette
- strong typography
- premium restraint
- readable copy
- clear conversion path
- strong section-by-section architecture

Avoid:

- flat brown gradient backgrounds
- old-site residue
- generic SaaS cards
- noisy sci-fi graphics
- Matrix code
- smoky or cloudy gradients
- random particles
- overdecorated panels
- diagrams that do not create spatial immersion
- anything that makes the page feel like a normal AI consulting homepage

## Success Standard

The redesign succeeds when the first impression is no longer:

> "This is a dark consulting website with tan accents."

It should be:

> "I am inside a black-and-tan architectural system built for AI activation."

Make the whole site feel like Lane 1, not like the old site with Lane 1 imagery added.
