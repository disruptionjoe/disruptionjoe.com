# Website Fresh Build Process

Status: guiding process for WI-050
Date: 2026-07-07
Work Card: WI-050
Owning repo for implementation: `djc-website`

## Purpose

This note captures Joe's requested process for the fresh disruptionjoe.com website work. It is the operating guide for `WI-050` until superseded by a later Joe decision.

## Core Constraint

Do not inspect or derive from the currently implemented website during the first drafting phase.

The first drafting phase should be based on Joe's new structural insights for each page, treated as the guiding architectural decisions and insights.

## Process

1. Joe shares structural insights for each page.

   Treat those structural insights as the architectural decisions and insights for the rebuild.

2. Draft sections, copy, and section-level image/media descriptions without looking at the current website.

   The output should include page sections, draft copy, and the best description of what imaging, interaction, exhibit, artifact, or other media belongs in each section.

3. Pause before brand-voice refinement.

   In a separate stage, refine the brand voice. Once the voice is fully refined, redraft all copy through that refined voice.

4. Establish brand design / mood-board key elements.

   Define the visual and sensory direction first: black / tan world, typography behavior, texture, field-manual / operating-notebook motifs, room cues, artifact style, diagram language, motion posture, and what should make the brand feel distinctive without becoming generic SaaS.

5. Design the experiential implementation concept.

   Using the brand design / mood-board direction, think through what an implementation should feel like if it is highly experiential, unlike ordinary consulting sites, and metaphorically demonstrates Joe's creativity and capabilities.

6. Only then update the website.

   No website implementation should happen before the architectural insights, draft structure/copy/media descriptions, brand-voice refinement, brand design / mood-board direction, and experiential concept have been worked through.

## Working Implications

- Treat prior website briefs as optional background only after the fresh structural drafting stage.
- Do not let the old walkthrough card (`WI-028`) constrain this process.
- Do not treat first-pass copy as final brand voice.
- Do not update website source until Joe confirms the brand design / mood-board direction and experiential concept are ready to move into implementation.
- GitHub push, deployment, publishing, external account updates, analytics/tracking changes, and non-website public-surface changes remain separately gated.
