# AI Accelerated Thinking Repo Rooms

Status: current implementation note for the Thinking page.

## Direction

The Thinking page should be an experiential walk through Joe's public repo architecture, not a standard content page.

The visitor should feel like they are moving through a black-and-tan Lane 1 building. Each public repo gets a room. A selected Lane 2 image sits in the room as an exhibit object. The repo description appears as large wall copy next to it.

## Current Public Wall

Only GitHub-public, public-safe repositories are currently included:

- `time-as-finality`
- `temporal-issuance`

- `architecture-of-legitimacy`

- `disruptionjoe-profile`
- `disruptionjoe.com`

`ai-native-epistemic-systems` exists in local public working context but was verified as private on GitHub on 2026-07-07, so it is not on the public wall.

## Design Guardrails

- Lane 1 remains the environment: corridor, chamber, wall, threshold, and architectural linework.
- Lane 2 images are exhibit objects inside that environment.
- Do not use Lane 2 images as page backgrounds or decorative wallpaper.
- Do not convert the repo rooms into cards, a blog list, or a normal project portfolio grid.
- Do not include private repos, client repos, vault material, or private working-system names without explicit public-safe approval from Joe.
- The page can be more immersive than the rest of the site, but it still needs readable wall copy, working links, and responsive layout.
